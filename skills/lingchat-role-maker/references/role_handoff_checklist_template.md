# 角色制作交接清单（<角色名>）

> 用法：与用户逐项交接打勾。**（Agent）** = Agent 代劳，仅同步进度，用户不用动手；
> **（用户）** = 需要用户亲手操作，Agent 给明确步骤（对应章节号）。
> **并行原则**：开工前一次问清全部问题 → 告诉用户这段时间做什么 → 各自开工；
> **耗时任务前置**（FULL 包下载、语音训练先开始，别等流程走到那一步）；
> **想到什么问题别自己决定，一律询问用户**（如 ffmpeg 没装 → 问用户，别擅自装）。
> **进阶项**（带「pro」标注）需加载进阶版 lingchat-role-maker-pro 对应章节。

## 阶段 0：开工前信息收集（Agent 逐项询问，说人话）

- [ ] （用户）角色名：__________（做哪个从者，说出名字就行；**如有其他形象如活动/泳装版也提供名字**，Agent 一并爬取语音）
- [ ] （用户）确认自训语音（**默认必做，本 skill 无跳过分支**，0.1）：下载训练模型包（约5G 最耗时最先下，0.5 链接）；不打算训练语音 → 本 skill 不适用（提醒：语音时长越多越好，推荐30min+/200条+）
- [ ] （用户）角色要做几个形象？除了初始样子，要不要愚人节版、灵衣、活动限定版？（2.1 前置）
- [ ] （用户）表情图工具：默认推荐「表情差分合成工具」直接甩链接（百度/夸克，教程 BV1T8g56LEnb，2.0）
- [ ] （用户）ffmpeg：「电脑上装过叫 ffmpeg 的音频转换软件吗？」**装过就在下面输入安装路径**（右键文件夹→复制为路径，0.7 询问技巧）；没有 → 我帮你下载（不擅自装）
- [ ] （用户）LingChat（角色运行的软件）：给链接自己装 or 我帮你装？（0.4；**若本机已装好直接输入 LingChat 安装路径**）
- [ ] （提示）开场只提一句「项目也能在手机上玩，有兴趣完成后帮你弄」——手机端现在不展开（pro 第 7 章）
