# references/ 参考成品资源

本目录存放从已跑通成品（梵高 v1.0）提取的**权威参考文件**，做新角色时直接对照/套用，避免凭记忆或反复找参考角色。

## 文件清单

| 文件 | 内容 | 用途 |
|---|---|---|
| `settings_van_gogh.yml` | 梵高 v1.0 成品 settings.yml（147 行） | **settings.yml 字段顺序/完整度母版**：新角色照此结构填（红线 2：改已有角色前必须先 read 目标文件、只改点名字段；字段顺序对齐这个母版；voice_models 完整 20 字段见 `voice_models_20字段.md`） |
| `settings_dante.yml` | 但丁版板块写法参考（含【主线剧情的记录】原文段落；**结构 + 板块示例母版，非完整成品**） | **【主线剧情的记录】板块写法参照**：梵高母版没有该板块，走主线剧情的角色（如但丁）照此填（速通版 4.4.2；完整内容需按速通版 1.4 爬取后填写） |
| `avatar_情绪文件名清单.md` | 梵高 avatar 各服装目录**真实文件清单** | 差分机械命名的依据：按参考角色 avatar 实际文件名逐字照抄（速通版 2.1/4.2），缺图/多图如实标注；⚠️ 其中 22~24 个文件含旧版遗留情绪，**新角色标准 = 20 情绪 + 头像 = 21 张**（4.2 决策规则） |
| `voice_models_20字段.md` | voice_models 完整 20 字段（含类型/示例值） | 填 settings.yml 时防漏字段（速通版 4.3/4.4.1） |
| `role_handoff_checklist_template.md` | 与用户逐项交接的打勾清单 | 全程交接用，随进度逐项勾选（0.7） |

## 进阶扩展（lingchat-role-maker-pro）

- 速通版只覆盖「角色能说话」的核心链路；**全量语音补全、BGM 补充语料、立绘补全、语速调优、本地 TTS、手机端、完整踩坑大全 → 加载进阶版 `lingchat-role-maker-pro`**（按需加载对应章节，见速通版 SKILL 第 9 章进阶指引）。
- 进阶版无独立 references，共用本目录的参考文件。

## 建议后续补充

- `<角色>_语音原文.txt`：做新角色时首次爬取的语音留档，可挑一份完整的放这里作解析格式示例（对应速通版 1.4）。
- `<角色>_资料原文.txt`：资料页留档示例（对应速通版 1.4）。
- 但丁完整 settings.yml：目前 `settings_dante.yml` 只收录了【主线剧情的记录】原文段落与结构骨架，完整成品（info/资料/示例语音等）待补——补时注意红线 1（全部来自 fgo.wiki 留档，不编造）。

## 注意

- settings 母版里 `user_name`、`system_prompt` 御主段是梵高 v1.0 的**用户私货**，仅供结构参考，新角色必须由用户提供自己的御主设定。
- 情绪文件名清单是**梵高这个角色**的实际文件，不同角色/不同用户可能不同（梵高文件里的 闭眼/感动 等是**旧版遗留情绪槽**，新版不触发但无害，不是标准情绪）；机械命名前仍以目标参考角色的实际目录为准。
